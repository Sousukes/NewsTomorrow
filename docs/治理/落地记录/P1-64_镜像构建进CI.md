## 一个必须先处理的细节：compose 的必填变量

compose 用 `${JWT_SECRET:?}` / `${POSTGRES_PASSWORD:?}` 强制拦截密钥默认值。
`docker compose build` **阶段**也会做变量插值，所以这两个变量必须在构建时存在，
否则 CI 直接红在「变量未设置」。

但构建阶段**不启动服务**，密钥并不进入任何运行态。于是 CI 里给**占位值**
（`ci-placeholder-*`），既通过插值，又用「值里带 placeholder」这条约定
防止有人顺手填成"看起来能用的默认密钥"（那会稀释 `:?` 拦截的意义）。
