## 批次 P1-47（2026-10-18）：管理端按业务域拆分（D2）

偿还 backlog 工程债组的 D2（M）。`app/routers/admin.py` 曾是 1695 行、34 个端点、
跨 6 个业务域的单文件。

## 拆成什么样

```
app/routers/admin/
├── __init__.py    # 只放共享：is_admin / require_admin / 聚合 router（127 行）
├── _shared.py     # 审计动作常量、record_audit、_PUB、ALLOWED_SCHEMES（69 行）
├── sources.py     252 行   RSS 源管理
├── news.py        240 行   资讯审核与下架（P1-20）
├── comments.py    305 行   评论治理（P1-22）+ 评论人工复核
├── words.py       254 行   评论敏感词库与命中日志（P1-23）
├── nickname.py    411 行   昵称词库与复核队列（P1-24）
├── users.py       166 行   管理员白名单（P1-14）+ 代重置密码（C4）
└── audit.py        69 行   运营审计（P1-15，只读）
```

URL 路径**一个字都没变**（`/api/admin/**`），`main.py` 也无需改动——
聚合 router 在 `__init__.py` 里 `include_router` 各子模块，前缀只在聚合层声明。
拆分后 34 个端点全部注册（`app.openapi()["paths"]` 枚举核对）。

**顺带做了一次归位**：`POST /comments/{id}/review` 在代码里落在 P1-23 段落
（和敏感词库共用 `moderation.engine`），但语义属于评论治理，已移进 `comments.py`。

## 三条不能违反的既有约定

1. **判定函数必须留在 `__init__.py`**：`is_admin` 在调用时解析模块全局
   `ADMIN_PHONES`，多个测试用 `monkeypatch.setattr(admin_mod, "ADMIN_PHONES", …)`
   打桩 break-glass 通道。搬到子模块就等于让那条测试静默失效。
2. **鉴权仍挂在聚合 router 上**：`dependencies=[Depends(require_admin)]` 对
   `include_router` 进来的路由全部生效——因此「新增子模块忘了加依赖」这种漏法
   依然在结构上不存在。`test_admin_guard.py` 用 openapi 枚举全部操作逐个断言
   401/403，拆完依旧全绿。
3. **子模块 `from . import require_admin`** 依赖「先定义、后导入」——底部才
   `include_router`，顶部导入就是循环依赖。

## 拆分暴露的真实设计问题：ADMIN_PHONES 有了两个真相源

`users.py` 里的白名单端点原本直接用模块级 `ADMIN_PHONES`（import 时从 config
取快照），而 `is_admin` 用的是包全局。**这两处一旦漂移**，症状是
「`is_admin` 说这个号是管理员，白名单接口说不认识它」——而且单元测试的
break-glass 打桩只对其中一个生效，另一半变成无法验证的盲区。

收敛为 `env_admin_phones()`：**运行期读包全局**，与 `is_admin` 同一个来源。
这正是拆分该有的收获——结构一改，原来靠"大家都在一个文件里"维持的隐式
约定就会浮出来。

## 拆分过程中被"发现"的两个工具坑

1. **静默错误用静态工具查，不要一个一个撞**。漏 import 的症状是 NameError
   且**只在运行到那一行才炸**。装了 `pyflakes` 一次扫出全部未定义名，
   比"跑测试→失败→补→再跑"快一个数量级。教训：第一版脚本按"片段里出现过"
   挑 import，漏了 `urlparse` 与一批 `models` 名字。
2. **脚本自身的顺序坑**：`logging` 只出现在 header 生成的
   `logger = logging.getLogger(...)` 里，而那行已被剔出正文——于是
   "按正文判断是否用到 `logging`"永远判否。**按文本推断 import 需求时，
   要先把生成物算进去**。

## 维护约定

- 新增管理端点放进**对应业务域**的子模块；找不到合适的域就新建一个，
  不要往 `_shared.py` 塞（它是常量与审计写入，不是端点堆放处）。
- 子模块**不要**自己声明 `APIRouter(dependencies=...)`，鉴权由聚合层统一施加；
  但**需要 actor 的端点**照旧写 `user: User = Depends(require_admin)`。
- 审计动作常量加到 `_shared.py`，不要在子模块里另定义一份。
