## 批次 P1-44（2026-10-18）：容器化 + 迁移前置钩子（D8）
偿还 backlog 工程债组最上方的 D8（S）。**没有 Docker 守护进程，所以镜像无法本地
验证**——这个边界写在代码注释、部署文档与测试模块说明里三处，并已登记为 backlog
后续项（CI 增加 `docker compose build`）。下面把"能验证的"与"只能静态断言的"
分清楚说。

**形态**：postgres + redis + `migrate`（一次性）+ backend + nginx(SPA + /api 反代)。
前后端**同源**——nginx 反代 `/api`，前端构建不带 `VITE_API_BASE`（留空 → 相对路径）。
于是浏览器只跟一个源打交道：CSP 能收得最紧、无 CORS 预检、不必把后端地址硬编进
构建产物。

**迁移前置钩子（本批的核心）**：本项目只有一个 schema 事实源（Alembic）。没跑迁移
就起服务，症状是「列不存在」——报错指向某处业务查询，真正原因却是环境没升级；
这类债在 CI 里看不见（CI 自己会先 upgrade），只在部署时炸。

- `scripts/entrypoint.sh`：`set -e` + `python -m alembic upgrade head` + `exec uvicorn`。
  **迁移失败即停**——起了服务也只会满屏 500，还会把"环境没升级"伪装成"代码有 bug"；
  `exec` 让 uvicorn 接管 PID 1，才能收到 SIGTERM 优雅退出
- compose 里 `migrate` 是一次性服务，backend 设 `RUN_MIGRATIONS=false` 并
  `depends_on: migrate: service_completed_successfully`。**多副本并发跑迁移会互相
  锁死同一份 DDL**，这个形态为 backlog 的 B5（抓取 worker 独立进程）留好了位置

**三个自己踩出来、已写进断言的坑**：

1. **`ENVIRONMENT=production` 下 `/api/health` 需要 `OPS_TOKEN`**（C5 fail-closed）。
   最初写的健康检查不带令牌 → 容器永远 unhealthy → frontend 因
   `service_healthy` 永不启动。修正：healthcheck 带 `X-Ops-Token`。
   **这是刻意的**——生产忘配密钥的后果就是"起不来"，而不是悄悄裸奔。
2. **`VITE_USE_MOCK` 必须显式传 `false`**：它的默认值是
   `API_BASE ? 'false' : 'true'`，而我们为了同源刻意留空 `VITE_API_BASE` →
   不显式传的话**生产镜像会静默跑起内置 mock**，界面上完全看不出来。
3. **entrypoint 调的是 `python -m alembic` 不是 `alembic`**（与 CI 同一形态）。
   测试最初按 `alembic` 控制台脚本打桩 → 真 alembic 跑了起来；本机恰好因
   WorkBuddy 的 python 没装 alembic 而快速失败，把问题**掩盖成"行为正确"**。
   改为打桩 `python`，并在 Git Bash 下实测三条路径：正常（alembic→uvicorn，exit 0）、
   迁移失败（只有 alembic，exit 1）、`RUN_MIGRATIONS=false`（只有 uvicorn）✓

**nginx 的两条容易踩的**：`/api/` **不做** SPA fallback（接口 404 时返回
index.html 会让前端 `json()` 报一个完全误导的解析错误）；`index.html` 不可缓存
（它是"引用了哪些哈希资源"的唯一清单，缓存住会让发版后用户一直拿旧版本）。

**CSP 只补一条**：nginx 只下发 `frame-ancestors 'none'`——它是 `<meta>` 里被规范
忽略、只有响应头才生效的那一条；其余策略仍来自构建期注入的 meta。**两份策略各写
一遍必然漂移**，而 CSP 多头是取交集生效的，只补表达不了的那条最稳。

**测试**：新增 `tests/test_deploy.py` **18 项**（3 项 entrypoint 行为在 POSIX shell
上**实际执行**、15 项部署文件不变量：迁移服务形态/依赖条件、db 不映射端口、
redis 不持久化、密钥用 `${VAR:?}` 强制拦截、`/api` 无 SPA fallback、index.html
no-cache、header CSP 只含 frame-ancestors、XFF 透传、healthcheck 带令牌、
构建期不跑迁移、文档必须提到必填密钥且必须声明"docker build 未验证"）。
