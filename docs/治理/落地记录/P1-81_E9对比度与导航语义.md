## 四个实现要点

1. **色值必须住在 CSS 里，门槛必须能在单测里断言**——两者冲突。解法：
   `palette.ts` 作事实源给测试用，`tokens.css` 保留字面值，**构建期校验二者一致**。
   反向验证过：把 secondary 改回 `#9a9fa8`，构建立刻报
   `tokens.css 与 palette.ts 不一致：light --color-text-secondary`。
2. **vitest 读不到 CSS**：`?raw` 与 `import.meta.glob` 对 `.css` 都返回空串（实测），
   所以不能"直接解析 tokens.css 断言"。这也是上面那个分工存在的原因。
3. **tertiary 不是"更浅的 secondary"而是不同角色**：分隔符 `·`、禁用提示这类
   不承载信息的元素留在 `#9a9fa8`；把元信息整体调深后，视觉层级没有塌。
4. **`border` 不强推 3:1**：卡片描边属装饰（WCAG 1.4.11 豁免），
   只给**表单控件**换 `border-strong`——否则所有卡片描边都会重得难看。
