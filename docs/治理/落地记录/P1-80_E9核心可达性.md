## 五个实现要点

1. **卡片是"链接"不是"按钮"**：用户对一条资讯的预期包含中键、右键新标签、复制链接。
   `<button>` 方案不仅语义不对，还会**非法嵌套**卡片内的收藏/更多按钮。
2. **`.exact.prevent` 是这套方案的关键**：只有无修饰键的点击交给 SPA 路由，
   带修饰键的点击保持浏览器原生行为。写成 `.prevent` 会杀掉"新标签打开"。
3. **覆盖层吃掉了"拖选卡片正文"**：这是有意接受的代价（信息流标题极少需要选中复制，
   而"点哪都能打开"是既有预期）。已在组件注释里写明，想复制请进详情页。
4. **`aria-modal="true"` 必须有焦点陷阱配套**：没有陷阱时读屏被告知"外界不可交互"，
   而 Tab 仍能跑到遮罩下方——焦点"消失在遮罩下面"是最让人迷失的坏法。
5. **监听器同步挂、聚焦等 DOM**：Escape 是"立刻要能用"的，不该等渲染完成；
   只有"聚焦第一个元素"需要等面板挂载。

## 两个自己踩的坑（均由测试抓出）

1. **`offsetParent !== null` 在 jsdom 里恒为 null**：用它判断"元素是否可见"会让
   焦点陷阱在测试里把**所有元素**判成不可见（10 个用例里 6 个失败）。
   改为沿祖先链查 `display` / `visibility` / `hidden`——浏览器与 jsdom 行为一致。
2. **测试点错了元素**：7 个既有用例（HomeFeed / History）都在点 `article` 根节点，
   而点击处理已移到覆盖链接。这类失败恰好证明"改动真的生效了"——测试改点
   `.mt-card__link` 后全部恢复。
