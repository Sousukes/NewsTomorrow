## 两个只在这里能测到的点

- **监听泄漏**：`StepUpDialog` 的 `window.addEventListener` 若不在 `onUnmounted`
  摘掉，每次路由切换都会累积一个监听器 —— 同一个 40304 会弹 N 次，还泄漏整个
  组件实例。这类 bug 在视图 spec 里看不出来，必须单独测卸载。
- **徽标刷新时机**：只在 `mounted` 刷一次时，用户读完消息返回首页，角标还是旧数字
  ——「我明明读完了」是最容易被投诉的那类小问题。

## 测试自身的两个坑（都被拦下）

1. **mock 的 state 必须是 `reactive`**：普通对象的 getter 不受 Vue 依赖追踪，
   改 `visible` 不触发重渲染，断言 `dialog` 存在就会假失败；
2. **挂了全局监听的组件必须逐用例卸载**：用 `enableAutoUnmount(afterEach)`。
   不卸载的话，上一个用例的监听器会响应下一个用例派发的事件，
   于是"卸载后不该再响应"的断言假失败——**这恰好说明这条断言是有意义的**：
   它连"别的实例还活着"都能探到。
