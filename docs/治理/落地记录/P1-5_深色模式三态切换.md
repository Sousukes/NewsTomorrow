## 批次 P1-5（2026-10-11）：深色模式三态切换（路线图第 1 项）
- **问题**：原深色仅 `prefers-color-scheme: dark` 媒体查询被动跟随系统，用户无法主动选择，
  且 `App.vue` / `Comments.vue` / `NewsDetail.vue` / `global.css` 有 4 处主题敏感硬编码
  （`#ebedf0` 页面底、`#333` 正文、`#666` 次要文字），深色下露馅。
- **方案**：三态 `system | light | dark`：
  - **单一来源**：`src/constants/theme.ts`（`THEME_MODES` / `THEME_OPTIONS` / `resolveTheme`），
    `system` 借 `matchMedia('(prefers-color-scheme: dark)')` 解析为实际 `light|dark`；
  - **生效方式**：由 JS 把**解析后的实际主题**写成 `<html data-theme="light|dark">` 并同步
    `color-scheme`（原生滚动条/表单控件也跟随）。CSS 只认 `:root[data-theme='dark']`——
    因此「跟随系统」与「手动指定」共用同一套深色令牌，**不必**在 CSS 里保留媒体查询分支；
  - **避免首屏闪白**：`main.ts` 在 `mount()` 之前先 `applyTheme()`（读 localStorage 偏好）；
  - **持久化**：偏好存于 `user` store（localStorage 的 `theme` 字段）；
  - **系统偏好实时响应**：`useTheme()` 监听 `matchMedia` 变化，`system` 模式下系统切换即跟随。
- **顺手清理的硬编码**：`App.vue`、`Comments.vue`、`NewsDetail.vue` 的 `#333/#666/#ebedf0`
  改走 `var(--color-text-primary|secondary|page-bg)`；`global.css` 的 `body` 底色同样令牌化，
  彻底消除深色下的"白底露馅"与首屏闪白。
- **入口**：`Profile.vue` 顶部新增「外观」分区，三段式 `button` 切换，当前态高亮。
- **测试**：前端 96 → **107 项**（新建 `constants/theme.spec.ts` 5 项 + `composables/useTheme.spec.ts`
  6 项：三态解析 / 非法值回退 system / `resolveTheme` 在 system 下读 media / 写入 `data-theme`
  与 `color-scheme` / system 监听 / 卸载清理监听器 / 持久化读写）。
