## 批次 P1-24（2026-10-16）：用户昵称敏感词校验（别名匹配 + 四形态归一化 + 待复核队列）
- **背景**：P1-23 给评论加了事前闸门，但昵称——评论之外第二个用户可控的展示面——
  此前的唯一写入点是**注册时的一句话**（`auth.py`，`body.name or 默认名`）：没有任何
  修改入口、也没有任何校验。一个脏昵称会跟着用户的每一条评论、每一个通知展示出去，
  等于让绕过者换个地方贴。本批补上 `PUT /me/nickname`（注册与改名同一条链）+
  昵称词库 + 命中日志 + 待复核队列。
- **设计①：三动作，刻意没有 mask**。`block` = 拒绝设置、**不保存**（40006，提示
  **不回显命中词**——回显等于给绕过者一份「哪些词不能起」的对照表）；`review` =
  **放行** + 置 `name_pending_review` 进人工队列（**默认**）；`allow` = 白名单
  **完全包裹**才豁免；`pass` = 原样保存并**清除**待复核标志（标志只描述**当前名字**
  的审核状态，当初提交过什么由命中日志留痕）。昵称没有「脱敏后照常发布」这个语义——
  那意味着改掉用户自己起的名字，而他此刻改不了。默认 review 而非 block：机器的判断是
  概率性的，「先放行再让人看」比吞掉用户的名字代价小。
- **设计②：归一化七类绕过 + 四形态**。逐字符 NFKC → `casefold()` → 只保留 Unicode
  `L*`/`N*`（空格/标点/零宽/emoji 全丢）；**重复压缩**（`collapsed` 形态，
  `aabbcc→abc`——昵称短、无语义，压缩误杀面小，故评论刻意不做的这里做）；
  **leetspeak**（`4/@→a、1/!/|→i、0→o…`，模式串与文本走同一条管道，一对一归并
  任意组合都安全）；**数字插字**（`nodigits` 形态，「博0彩→博彩」，与 leetspeak
  互补：0 当字母 o 用还是当噪声删，两种形态都扫）；**繁简 curated 表**（零运行时
  依赖，未覆盖的繁体变体由运营配别名）。四形态 `base/nodigits/collapsed/
  collapsed-nodigits` 各带 index_map，命中回到原文定位。
- **设计③：拼音谐音走词条别名**。同音字替换（傻→莎）没有字符级算法可解（需要
  字→拼音表），由运营发现后补 `aliases`（拼音全拼/首字母/谐音/变形），与主词走
  **同一条归一化管道**——零新依赖下覆盖「shabi」「sb」类字母绕过的路线。
- **设计④：引擎复用不重造，资源不复用**。**复用** `moderation.AhoCorasick` 自动机与
  指纹缓存模式（不复制第二份实现）；**新表不复用** `sensitive_words`——不同语义的
  资源不挤进同一张表，否则「这个词是拦评论还是拦昵称」永远说不清。
- **设计⑤：复核队列回答「哪个提交」而非「他现在叫什么」**。用户完全可能已经把名字
  改掉了（`name` 是当前值），于是三个标量子查询（`flaggedAt`/`flaggedName`/
  `flaggedMatched`）都取该用户最近一条 **review 级**命中的 `created_at`/`snippet`/
  `matched`。复核只清标志 + 写 `name_reviewed_at`，**不改昵称本身**——名字是用户
  自己起的，复核是「人看过了」这个事实，不是运营替他改名。
- **数据结构（迁移 0024）**：`nickname_words`（`word` 唯一索引 / `action` /
  `category` / **`aliases` JSON 列**（PG 上 JSONB）/ `enabled` / `hit_count` /
  `created_by` / `created_at` / `updated_at`）、`nickname_hits`（记词本身 +
  **`matched` 实际命中模式** / `source`(register|update) / `snippet`；**block 也
  留痕**——「拦了多少次改名」不能是黑箱）、`users` 增 `name_pending_review`
  （非空默认 false、**不建索引**——待复核集预期很小，加了只会拖慢每次昵称写入）+
  `name_reviewed_at`。
- **配置**：`NICKNAME_MODERATION_ENABLED` / `MIN_LENGTH`(2) / `MAX_LENGTH`(24) /
  `MIN_WORD_LEN`(2) / `CACHE_TTL_SECONDS`(30) / `MAX_WORDS`(20000) /
  `COLLAPSE_REPEATS`(true) / `ALLOWED_SYMBOLS`(`_-·.・`，空格代码内补——
  `_env` 会 strip 整个值，尾随空格在环境变量里活不下来）。
- **误杀控制**：默认 review / allow 包裹豁免 / 最短词长 2 挡在入库且**主词与每个
  别名逐个查**（引擎加载会静默跳过过短形态，「配了却没生效」比报错难发现得多）/
  block 不回显 / 日志留 snippet / 停用优于删除 / **未知 action 兜底 review** /
  **不做追溯式回填**（队列针对新提交，不回头翻旧账）。
