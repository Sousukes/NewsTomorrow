## 2. 组件 Props 速查
### 2.1 Button.vue（按钮）
设计系统对应：主按钮 / 次按钮 / 文字按钮 / 禁用态 四态

| Prop | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `variant` | `'primary' \| 'secondary' \| 'text'` | `'primary'` | 主按钮（蓝胶囊）/ 次按钮（白底蓝描边）/ 文字按钮（蓝链接） |
| `disabled` | `boolean` | `false` | `true` 时强制禁用态（灰底、不可点），覆盖 `variant` 样式 |
| `block` | `boolean` | `false` | 是否占满父容器宽度（登录、去逛逛、重新加载等用） |
| `size` | `'md' \| 'lg'` | `'md'` | `md`=高度 44；`lg`=高度 48（登录主按钮用） |
| `label` | `string` | — | 按钮文案 |

事件：`click`

### 2.2 AppNav.vue（顶部导航）
设计系统对应：通用标题导航 / 首页品牌导航 / 搜索导航 / 详情-作者关注 四变体

| Prop | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `variant` | `'title' \| 'brand' \| 'search' \| 'detail'` | `'title'` | 四变体切换 |
| `title` | `string` | `''` | 标题文案；`brand` 变体固定显示「明日头条」 |
| `showBack` | `boolean` | `false` | 是否显示返回箭头（title / detail 用） |
| `showSearch` | `boolean` | `false` | 是否显示搜索图标（brand 用） |
| `showMessage` | `boolean` | `false` | 是否显示消息图标（brand 用） |
| `showMore` | `boolean` | `false` | 是否显示更多图标（detail 用） |
| `author` | `{ name; avatar; time; followed } \| null` | `null` | `detail` 变体作者信息（头像 / 名称 / 时间 / 是否已关注） |

事件：`back` / `search` / `message` / `more` / `follow(author)`

### 2.3 ChannelTabs.vue（频道栏）
设计系统对应：推荐（激活蓝 Medium）+ 热点/视频/科技/财经/体育/汽车（灰 Regular）

| Prop | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `tabs` | `Array<{ label: string; active?: boolean }>` | `[]` | 频道列表，`推荐` 默认激活 |
| `modelValue` / `activeKey` | `string \| number` | `0` | 当前激活频道 key |
| `scrollable` | `boolean` | `true` | 频道过多时横向滚动 |

事件：`update:modelValue` / `change(key)`

---

### 2.4 TabBar.vue（底部标签栏）
设计系统对应：胶囊式，4 Tab（首页 / 视频 / 消息 / 我的），激活项蓝底白字

| Prop | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `items` | `Array<{ key; label; icon }>` | 4 项固定 | 首页(home) / 视频(video) / 消息(message) / 我的(mine) |
| `modelValue` / `active` | `string` | `'home'` | 当前激活 Tab key |
| `fixed` | `boolean` | `true` | 是否吸底固定 |

事件：`update:modelValue` / `change(key)`

> 注：设计中「视频」为首页内频道，未单列屏；消息屏（S11）已建，激活态为消息。

### 2.5 NewsCard.vue（新闻卡片）
设计系统对应：三图 / 左文右图 / 纯文字 / 视频 四变体

| Prop | 类型 | 说明 | 对应接口字段 |
|---|---|---|---|
| `variant` | `'triple' \| 'left-right' \| 'text' \| 'video'` | 卡片样式 | — |
| `title` | `string` | 标题（多行截断） | `title` |
| `summary` | `string` | 摘要（左文右图 / 纯文字 / 视频 显示） | `summary` |
| `source` | `string` | 来源 | `source` |
| `commentCount` | `number \| string` | 评论数 | `commentCount` |
| `time` | `string` | 时间 | `time` |
| `playCount` | `number \| string` | 播放数（`video` 变体，替代评论展示位） | `playCount` |
| `images` | `string[]` | 三图变体，取前 3 张 | `images` |
| `cover` | `string` | 左文右图配图 / 视频封面 | `cover` |
| `isTop` | `boolean` | 置顶标签（纯文字变体左上角，蓝字描边） | `isTop` |

事件：`click(card)` / `imageClick(url, index)`

**四变体渲染映射**

| 变体 | 展示元素 |
|---|---|
| `triple` 三图 | 标题 + 三图(images[0..2]) + 元信息(来源·评论·时间) |
| `left-right` 左文右图 | 标题 + 摘要 + 配图(cover) + 元信息(来源·评论·时间) |
| `text` 纯文字 | 标题 + 摘要 + (isTop? 置顶) + 元信息(来源·评论·时间) |
| `video` 视频 | 封面(cover) + 播放数 + 元信息(来源·播放·时间)；不显示评论数 |

> 元信息在 S10 搜索结果中已拆为「来源 · 评论 · 时间」三个独立节点，与 NewsCard 渲染逻辑一致。
