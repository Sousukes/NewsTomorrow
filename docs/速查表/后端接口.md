## 3. GET /news 接口字段
- **Method**：`GET`
- **Path**：`/news`
- **Query 参数**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `channel` | `string` | 否 | 频道 key，默认 `recommend`（聚合所有频道）；对应 ChannelTabs |
| `page` | `number` | 否 | 页码，默认 `1`（offset 分页，未传 `cursor` 时生效） |
| `pageSize` | `number` | 否 | 每页条数，默认 `20`，上限 100 |
| `cursor` | `string` | 否 | **游标分页**（推荐）：传上一页返回的 `nextCursor`，深分页 O(1)，优先于 `page` |
| `keyword` | `string` | 否 | 搜索关键词（S10 搜索结果用，走 `/news/search`） |

- **排序契约**：置顶（`isTop`）优先 → 绝对发布时间倒序 → `id` 倒序（稳定，避免翻页重复/漏项）。

- **Response 200**

```json
{
  "code": 0,
  "data": {
    "list": [
      {
        "id": "string",
        "title": "string",
        "summary": "string",
        "source": "string",
        "commentCount": "number",
        "time": "string",
        "images": ["string"],
        "cover": "string",
        "videoUrl": "string",
        "playCount": "number",
        "isTop": "boolean",
        "channel": "string",
        "variant": "string"
      }
    ],
    "total": "number | null",
    "page": "number | null",
    "pageSize": "number",
    "nextCursor": "string | null",
    "hasMore": "boolean"
  }
}
```

> 游标模式下 `total`/`page` 为 `null`（避免每页全表 count，正是性能收益来源）；客户端以 `hasMore` + `nextCursor` 续接。

| 字段 | 类型 | 对应组件 Prop | 说明 |
|---|---|---|---|
| `id` | string | — | 新闻唯一 id |
| `title` | string | `NewsCard.title` | 标题 |
| `summary` | string | `NewsCard.summary` | 摘要（文档已含该字段） |
| `source` | string | `NewsCard.source` | 来源 |
| `commentCount` | number | `NewsCard.commentCount` | 评论数 |
| `time` | string | `NewsCard.time` | 发布时间 |
| `images` | string[] | `NewsCard.images` | 配图 URL（三图变体取前 3） |
| `cover` | string | `NewsCard.cover` | 单图 / 视频封面 |
| `videoUrl` | string | — | 视频地址（video 变体播放用） |
| `playCount` | number | `NewsCard.playCount` | 播放数 |
| `isTop` | boolean | `NewsCard.isTop` | 置顶 |
| `channel` | string | — | 所属频道 |

## 3.1 GET /search/suggest 接口字段（E2 / P1-70）

- **Method**：`GET`
- **Path**：`/search/suggest`（独立前缀 `/api/search`，与 `/api/news/search` 不冲突）
- **鉴权**：**不需要登录**（热搜是公开统计，相似词来自公共日志且不含用户字段）

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `q` | `string` | 否 | 输入词；空 / 纯空格 → 200 + 空列表（不是错误，输入框刚聚焦就该是这个结果）。上限 50 字 |
| `limit` | `number` | 否 | 默认 `8`，**1~20**（越界 422，mock 同样拒绝而非静默夹取） |
| `days` | `number` | 否 | 候选词统计窗口天数，默认 `7`，1~90 |

- **刻意不写 `search_logs`**：联想是**输入过程**不是搜索行为，写进去会把
  「新能源汽」「新能源汽⻋」这类中间态灌进热搜榜。契约里有专门一条盯着。

- **Response 200**

```json
{
  "code": 0,
  "data": {
    "list": [
      { "term": "新能源汽车", "kind": "hot", "hitCount": 12 },
      { "term": "暴雨蓝色预警发布", "kind": "title", "hitCount": 0 }
    ],
    "keyword": "新能源"
  }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `term` | string | 建议词（点它 = 带这个词进搜索结果页） |
| `kind` | `hot` \| `correct` \| `title` | `hot`=热搜邻居（**优先级最高**）、`correct`=纠错、`title`=标题前缀 |
| `hitCount` | number | 被搜索次数；`title` 类没有搜索行为，恒为 `0`（前端按 `kind` 决定是否展示） |
| `keyword` | string | 回显归一化后的输入（去空白 + 截断），前端据此判断「这份建议属于哪次输入」 |

> **只给词，不带资讯字段**：把标题当结果返回会让「选词」和「看结果」互相干扰。
> 同一 `term`（按小写比较）只出现一次；`hot` 内按次数倒序、`correct` 内按相似度倒序，
> 两者都以次数倒序 + 词字典序兜底。

## 4. 待确认 / 注意事项
1. **命名约定**：组件 Props、事件名（如 `update:modelValue`）为通用 Vue 3 约定建议，需与《AI掘金头条新闻系统 - 前端开发文档 (Vue 3)》实际命名逐一对齐。
2. **视频 Tab**：设计中为「首页」内频道；前端已额外落地为独立整页（`/video`，`Videos.vue`）。视频目前仅展示封面 + 播放数，真实播放（`videoUrl`）待接。消息 / 评论相关接口文档未完整列出，待后端补全。
3. **语义色**：`#E5484D` 为功能性错误色，**仅用于表单报错与错误提示**，与品牌主蓝无关；不要用于品牌、强调或装饰。
4. **置顶标签**：使用主蓝 `#2D6CFF`（文字 + 描边），不要误用错误红。
5. **配图**：设计稿中为渐变占位，实际接入 `images` / `cover` 字段的远程 URL。
