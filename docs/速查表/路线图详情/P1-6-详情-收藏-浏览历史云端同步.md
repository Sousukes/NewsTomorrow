#### P1-6 详情：收藏 / 浏览历史云端同步
**接口**（全部需登录，按 `user_id` 隔离）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/me/favorites` | 我的收藏（按收藏时间倒序），返回 `{ ids, list }` |
| POST | `/api/me/favorites` | 收藏（幂等；资讯不存在 → 404） |
| PUT | `/api/me/favorites` | **并集合并** `{ ids }`，只增不删 |
| DELETE | `/api/me/favorites/{newsId}` | 取消收藏（幂等） |
| GET | `/api/me/history` | 浏览历史（按浏览时间倒序，上限 50），返回 `{ ids, list }` |
| POST | `/api/me/history` | 记录浏览（同一条只刷新时间；资讯不存在时**静默忽略**） |
| PUT | `/api/me/history` | **并集合并** `{ ids }`，随后裁剪到上限 |
| DELETE | `/api/me/history` | 清空 |

**本地存储键**（离线缓存）

| 键 | 内容 |
| --- | --- |
| `mingri-toutiao:user` | 登录态 / 当前账号 id / 主题偏好（**不含**标记数据） |
| `mingri-toutiao:marks:anonymous` | 未登录时的收藏与历史 |
| `mingri-toutiao:marks:u<id>` | 各账号各自的收藏与历史 |

> ✅ 登出**不会**丢失数据：仅切回匿名作用域，账号数据仍保留在 `marks:u<id>`，重新登录立即恢复。
> 各账号本地缓存互不可见，因此**不存在换账号串数据**。
> 旧格式（标记内嵌在 `mingri-toutiao:user`）会自动迁移到匿名作用域，不丢已有数据。
