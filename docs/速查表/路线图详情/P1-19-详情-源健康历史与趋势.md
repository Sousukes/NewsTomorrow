#### P1-19 详情：源健康历史与趋势
**补的缺口**：P1-16~P1-18 的健康字段始终只是**一个点**——`last_status` 只有"现在挂没挂"，
`last_item_count` 只有"最近一次抓到几条"。没有时间维度，四个问题一个都答不了：
烂了多久 / 是否规律抖动 / 改动前后有没有好转 / **成功但条数从 30 持续掉到 3**
（最后一条结构性看不见——源永远是绿的）。

| 设计 | 规则 |
| --- | --- |
| 存原始事件 | 每轮一行，**不存每日聚合**——事后换窗口（7/30 天）重看还有数据（同 `SearchLog` 思路） |
| 只记真实尝试 | 礼仪/熔断跳过的源本轮没发请求，记一行会伪造"尝试过"；与「跳过不刷新健康状态」**同一条口径**（`run_ingest` 的 `finally` 里与 `record_fetch_result` 相邻，两处各自提交、各自吞异常） |
| 清理 | 按时间删、**不设 `keep_min` 保底**（与 `prune_old_news` 刻意不同）："最近 N 天"就是排障取证的全部价值 |
| 索引 | 只建复合 `(source_key, at)`，**不建 `at` 单列**——清理查询两万行全表扫描几毫秒，不值得拖慢每轮十几次写入 |
| `avgItems` | **成功轮次**的平均：失败轮天然 0 条，混进来"条数退化"会被失败率掩盖 |
| `rate` | 无尝试时返回 **None 不是 0**——`0` 会把"没抓过"伪装成"全挂了" |
| 缺天不补零 | 补零会把"没抓"伪装成"抓了但全失败"；前端按 `days` 铺好格子再按日期落点 |
| `days` 收敛 | `window_days()` 把请求收敛到保留期，响应回传生效的 `days` 与 `keepDays`（请求 90 天而只留 30 天，只会得到 60 个空格子） |

**接口**：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/sources` | 每行 +`health`（`{attempts, ok, rate, avgItems}`，无尝试为 `null`）+ 顶层 `healthDays`（列表摘要窗口） |
| GET | `/api/admin/sources/{key}/health` | 单源趋势：`summary` 窗口总览 / `points` 按天序列 / `failures` 最近失败原文 + `kind`；`days` 参数 1~365，默认取保留期 |

**前端影响面**：

| 项 | 变化 | 涉及文件 |
| --- | --- | --- |
| 类型 | `SourceHealthBrief` / `SourceHealthSummary` / `SourceHealthPoint` / `SourceHealthFailure` / `SourceHealth`；`RssSourceItem.health`；`fetchSources()` 改返回 `{list, healthDays}` | `types.ts` |
| 接口层 | `toHealthBrief()` / `toHealthPoint()` / `toHealthFailure()`（`rate` 收敛 0–1、坏日期/无时间点丢弃、`kind` 白名单）；`fetchSourceHealth(key, days?)` | `api/admin.ts` |
| 组件 | `SourceHealthTrend.vue`（`mt-health` 前缀）：四指标 + **条数下滑**（最近不足前期六成、样本 ≥4 天才提示）与**规律抖动**（≥3 次失败且六成以上落在同一小时 → "像是对方站点的维护窗口"）两条**只有历史看得见的结论**；全失败日柱高强制 6%，不塌成零像素 | `components/SourceHealthTrend.vue` |
| 页面 | 列表健康 chip（`rate <0.5` 红 / `<0.9` 琥珀 / 无尝试灰"—"）+「趋势」就地展开（一次只开一个，失败只在行内报错不掀页） | `views/AdminSources.vue` |
| mock | `SEEDED_HEALTH` 两个样本（`people_scitech` 条数下滑 / `xinhua_fortune` 凌晨规律失败）；`GET /admin/sources/:key/health` 路由；`days` 非法值 422 对齐真实后端 | `mock-server/server.mjs` |

> 不存在的 key，种子从未生效、而用固定 fixture 的单测照样全绿——一类静默失效。
