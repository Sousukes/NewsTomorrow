#### P1-23 详情：评论敏感词自动审核（可配置词库 / 热更新 / 命中日志）
**补的缺口**：P1-22 给了运营「先隐藏再核实」的处置能力，但处置仍完全依赖**人先看见**——
从内容发出到被看见之间是一段无人值守窗口，广告、引流、博彩就活在这段窗口里。
本批补上**写入侧的自动审核**：词库可配置维护、支持热更新、命中留痕供审计与统计。

| 设计 | 规则 |
| --- | --- |
| 只堵唯一写入口 | `POST /api/news/:id/comments` 是主评论与回复的**唯一**写入路径，检测在**落库之前**；**读路径刻意不加**——读多写少，不给每次列表刷新付一次永远用不上的成本。前端校验只防误触，**服务端是唯一可信边界** |
| 三动作 | `block` = 拒绝提交、**不落库**（**40005**）、提示**不回显命中词**；`mask` = 替换为 `*` 后发布并标 `pendingReview`（**默认**）；`allow` = 白名单，命中区间**被 allow 词完全包裹**才豁免 |
| 默认 mask 而非 block | 误杀成本考虑：block 让人「说了半天没反应还不知道为什么」，mask 最多是内容变形，且留复核入口。**不回显命中词**——回显等于教人怎么改写绕过 |
| 归一化匹配 | 逐字符 NFKC → `casefold()` → 只保留 Unicode `L*`（字母，含 CJK / 假名 / 谚文）与 `N*`（数字）；空格 / 标点 / 零宽 / 符号 / emoji 全丢。**保留原文下标映射**，脱敏改的是原文、长度取**词长**而非区间长度。实测四类绕过（空格分隔 / 夹标点 / 全角空格 / 零宽字符）**全部拦截** |
| 不做重复压缩 | `好好` 压成 `好` 的误杀率远高于它拦下的量 |
| 算法 | Aho-Corasick 自动机，`O(n + 命中数)`，与词库规模无关（涨到两万条仍是扫一遍正文） |
| 热更新双保险 | 指纹 `COUNT(*) + MAX(updated_at)`；`engine.invalidate()` 同时清 `_checked_at` 与 `_fingerprint`（**只清时间不清指纹 = 停用后仍走旧缓存，热更新失效**）；本进程保存即生效，集群靠 TTL 30s 兜底 + `POST /admin/words/reload` 手动触发 |
| 误杀控制七条 | 默认 mask / allow 豁免 / **最短词长 2** 挡在入库 / **昵称命中一律降级 mask**（昵称是历史数据，block 会让人发不出言）/ block 不回显命中词 / 日志留**原文**片段（`SNIPPET_CONTEXT=30`）/ **停用优于删除**（删了就失去统计与复盘依据） |

**结构契约（迁移 0023）**

| 表 / 列 | 说明 |
| --- | --- |
| `sensitive_words` | `word` **唯一索引** / `action` / `category` / `enabled` / `hit_count` / `created_by` / `created_at` / `updated_at` |
| `sensitive_hits` | 记**词本身**而非 `word_id`（词被删了日志仍可解释）；`field` 区分 `content\|name`；**block 时 `commentId` 为 NULL**（没落库就没有 id）；`snippet` 存**原文**（脱敏不可逆，判断误杀全靠它） |
| `comments` +2 列 | `pending_review`（非空默认 false，**不建索引**）/ `reviewed_at`；**与 `hidden` 正交**——脱敏发布是「待复核」，运营隐藏是「已处置」，两件事不能挤进一个字段 |

**接口**（均需登录 + 具备管理能力）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/words` | `keyword`（≤50）/ `action`（空\|block\|mask\|allow）/ `enabled`（三态）/ `limit`+`offset`（运营要「一遍扫完 + 能跳页核对」，词库量级不支持 keyset 的那点收益）；排序 `hitCount DESC, id DESC`——高频词要么是热点、要么是误杀大户，都得先看见 |
| POST | `/api/admin/words` | `{word, action, category, enabled}`；归一化后不足 2 个有效字符 → **42202**；重复词 → **40905**；保存即 `invalidate()` |
| PATCH | `/api/admin/words/:id` | 局部更新，**不允许改词本身**（改词等于删一条加一条）；字段级 diff 审计，无变化不记 |
| DELETE | `/api/admin/words/:id` | 审计留快照（删错要知道原样）；不存在 **40406**。通常**停用优于删除** |
| POST | `/api/admin/words/reload` | 强制重建**本进程**索引；改词已自动失效，这是给集群其他实例用的 |
| GET | `/api/admin/moderation/hits` | 命中日志（**只读、不清理**）：`word` / `action`（block\|mask）/ `field`（content\|name）/ `limit`+`cursor`(id keyset)；返回 `{ list, total, hasMore, nextCursor }` |
| POST | `/api/admin/comments/:id/review` | 通过人工复核（**幂等**）：只清 `pendingReview` + 写 `reviewedAt`，**不改可见性、不动计数**；不存在 **40405** |

**审计新动作**

| action | 触发 | detail 结构 |
| --- | --- | --- |
| `word.create` | `POST /admin/words` | `{ word, action, category, enabled }` |
| `word.update` | `PATCH /admin/words/:id` | `{ changes: {字段: [旧, 新]} }` |
| `word.delete` | `DELETE /admin/words/:id` | `{ snapshot }` |
| `word.reload` | `POST /admin/words/reload` | `{ count }` |
| `comment.review` | `POST /admin/comments/:id/review` | `{ content（前 50 字）, newsTitle, userName }` |
