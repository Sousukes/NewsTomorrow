#### P1-14 详情：管理员白名单（指定账号）
**判定模型（后端 `admin.is_admin(phone, db)` 唯一入口）**

| 来源 | 说明 | 变更方式 |
| --- | --- | --- |
| `ADMIN_PHONES` 环境变量 | break-glass 应急通道，重启即生效、不依赖库 | 改部署配置 + 重启 |
| `admin_users` 表（迁移 0015） | 日常运营，增删**即时生效**，支持预授权 | 应用内「管理员管理」页 |

两边都为空 = 管理能力整体关闭（403）。

**接口**（均需登录 + 具备管理能力）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/users` | 白名单列表，返回 `{ list, total, envAdminCount }`；行含 `registered` / `name` / `addedBy` / `createdAt` |
| POST | `/api/admin/users` | 添加入参 `{ phone, note? }`；已在任一来源 40903、形态非法 422 |
| DELETE | `/api/admin/users/{phone}` | 移除；不存在 40403；**末位保护** 40904 |

**前端影响面**

| 项 | 变化 | 涉及文件 |
| --- | --- | --- |
| 接口层 | 新增 `fetchAdminUsers` / `addAdminUser` / `removeAdminUser`（仅真实后端，复用 `ensureRealBackend` 守卫）；行数据经 `toAdminUser()` 归一化，形态非法手机号丢弃 | `api/admin.ts` |
| 页面 | 新增 `views/AdminUsers.vue`（双源说明卡 + 添加表单 + 列表 + 移除确认；toast 3s 自动消失） | `views/AdminUsers.vue` |
| 入口 | 个人中心菜单「管理员管理」+ 源管理页页头跳转；`/admin/users` 路由 | `views/Profile.vue`、`views/AdminSources.vue`、`router/index.ts` |
| 类型 | 新增 `AdminUserItem` / `AdminUserList` / `AdminUserInput` | `types.ts` |
