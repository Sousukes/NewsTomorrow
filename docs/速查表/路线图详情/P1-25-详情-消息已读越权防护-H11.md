#### P1-25 详情：消息已读越权防护（H11）
**问题（审查发现，见 `docs/review/architecture-review-2026-10-17.md`）**

| 层面 | 修复前 | 风险 |
| --- | --- | --- |
| 鉴权 | 依赖 `get_current_user_optional` | docstring 写「需登录」，实际匿名可调用 |
| 可见性 | `db.get(Message, id)` 直接取行 | 任何用户凭 id 可读他人**定向**消息全文 |
| 响应 | 不存在时 `ok(None, "消息不存在")` 200 | 「标记了别人的消息」在响应上表现为成功，越权不可观测 |

**判定口径**：`visible_condition` 是唯一真源——**定向给自己 + 广播**。不可见一律与「不存在」同码
**40400**，与资讯软下架（`hidden` 与「不存在」同码）同一条口径：对外不暴露「它存在但你看不到」。

**接口契约**

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| PATCH | `/api/messages/{id}` | ✅ 需登录 | 标记单条已读（幂等）。不存在 / 不可见 → **40400**；未登录 → **40100** |
| GET | `/api/messages` | 可选 | 不变（只返回可见范围） |
| GET | `/api/messages/unread-count` | 可选 | 不变 |
| POST | `/api/messages/read-all` | 可选 | 不变（本就只标记可见范围，且只返回计数，无泄露面） |

**前端影响面**

| 项 | 变化 | 涉及文件 |
| --- | --- | --- |
| store | 无登录态时 `markRead` / `markAllRead` **只落本地**、不发起写请求 | `stores/messages.ts` |
| http | 401 仅在**原本持有 token** 时广播 `mingri:unauthorized`（游客不再被 `main.ts` 跳登录页） | `api/http.ts`、`main.ts`（监听方不变） |
| API 层 | `markMessageRead` / `markAllMessagesRead` 无签名变化；调用方已 try/catch 静默 | `api/messages.ts` |

**测试**：后端 `TestMarkReadAuthorization`（4 项）+ `TestMessages` 契约变更 2 项；
前端「游客 markRead 不发起请求」「游客 401 不广播事件」2 项。
