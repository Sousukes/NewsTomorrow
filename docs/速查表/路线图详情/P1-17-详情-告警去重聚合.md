#### P1-17 详情：告警去重聚合
**触发**：本轮「过了节流窗口」的待告警源数量 ≥ `FEED_ALERT_AGGREGATE_MIN`（默认 3）
→ 合并为 **1 条 / 收件人**；否则维持 P1-16 的逐源直发。

> 聚合**不是越早越好**：只有 1 条时套一层汇总反而多一次点击。阈值以下保持直发。

| 项 | 规则 |
| --- | --- |
| 标题 | `信源异常汇总（N 条）`——条数放**标题**，因为消息预览是单行省略号，摘要尾部看不见 |
| 摘要 | `抓取失败 3 条（A、B、C）；从未成功 2 条（D、E）`——**按原因分组**而非罗列源名 |
| 分组顺序 | 抓取失败 > 超时未抓取 > 从未成功（严重度） |
| 组内顺序 | `weight` 降序、key 升序——被列出的名字就是最该先看的几个 |
| 列举上限 | `FEED_ALERT_AGGREGATE_LIST`（默认 5），超出以「等」概括，**总量仍准确** |
| 名字截断 | >10 字截断，且**截断后去重**（同站点多频道会撞前缀，并列相同字符串是噪音） |
| 锚点 | 两个分支都推进 `last_alerted_at`；聚合分支漏推进会让整批下一轮**再发一次** |
