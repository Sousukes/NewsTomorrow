**F1 · CI 迁移校验**

```yaml
- name: 迁移升级（SQLite，兼作启动前置）
  run: python -m alembic upgrade head
- name: 迁移漂移检查（alembic check · PostgreSQL）   # 需 postgres service
  run: python -m alembic upgrade head && python -m alembic check
```

**`alembic check` 必须在 PostgreSQL 上跑**：SQLite 无法反射外键与 GIN 索引，
会把 `comments` 的三个 FK、`messages` 的 FK、`ix_news_title_trgm` / `ix_news_summary_trgm`
全部误报成「新增迁移操作」（本地实测复现）。这是本批最容易被"CI 红了就跳过"掩盖的坑。

另修一处：**探活失败此前会被当成成功**（`curl -sf … && break` 失败后循环照常结束），
契约检查可能跑在一个根本没起来的后端上；现在显式 `exit 1` 并打印 `/tmp/api.log`。

**测试**：新增 `components/AppNav.spec.ts`（3 项）+ `components/TabBar.spec.ts`（3 项）——
断言**渲染结果里不存在任何 `#` 开头的 stroke/fill**，且描边为 `currentColor`。
