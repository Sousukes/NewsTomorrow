#### P1-15 详情：运营审计（谁改了什么）
**留痕范围与动作命名**

| action | 触发 | detail 结构 |
| --- | --- | --- |
| `source.create` | `POST /admin/sources` | `{ snapshot: {…} }` |
| `source.update` | `PATCH /admin/sources/{key}`（**仅当有字段变化**） | `{ changes: { 字段: [旧, 新] } }` |
| `source.delete` | `DELETE /admin/sources/{key}` | `{ snapshot: {…} }`（删前取） |
| `source.reset` | `POST /admin/sources/reset` | `{ seeded: n }` |
| `admin.add` / `admin.remove` | `POST` / `DELETE /admin/users` | `{ note }` |

**接口**（需登录 + 具备管理能力）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/audit` | 时间线，**新的在前**；`cursor` 为自增 `id`（非时间戳，规避秒级同值抖动），`target` 可按对象过滤 |

**前端影响面**

| 项 | 变化 | 涉及文件 |
| --- | --- | --- |
| 接口层 | 新增 `fetchAuditPage({ limit, cursor, target })`；游标由服务端下发、客户端不解析 | `api/admin.ts` |
| 页面 | 新增 `views/AdminAudit.vue`：中文动作标签、字段级变更（`enabled` 显示「启用→停用」）、加载更多 | `views/AdminAudit.vue` |
| 入口 | 源管理页每行「历史」→ `/admin/audit?target=<key>`；管理员页「审计记录」 | `views/AdminSources.vue`、`views/AdminUsers.vue`、`router/index.ts` |
